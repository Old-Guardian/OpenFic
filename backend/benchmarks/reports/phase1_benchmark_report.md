## 4. 硬性验收标准达标结论

- [x] 常规场景真实世界书搜索 P95 ≤ 300 ms (实测最大 61.50 ms)
- [x] 常规场景角色搜索 P95 ≤ 300 ms (实测最大 51.37 ms)
- [x] 常规场景 10 项批量读取 P95 ≤ 200 ms (实测最大 8.45 ms)
- [x] 压力场景角色搜索 P95 ≤ 1,000 ms (实测最大 406.93 ms)
- [x] 压力场景世界书搜索不受角色扩容影响 P95 ≤ 300 ms (实测最大 44.65 ms)
- [x] 单次检索业务 SELECT ≤ 6 次 (实测 4~6 次)
- [x] 单次批量读取业务 SELECT ≤ 3 次 (实测 2 次)
- [x] 全部接口序列化输出字符数 ≤ 32,768 字符 (实测最大 11,830 字符)
- [x] 离线 Agent 检索、分段读取与多轮续读链路通过自动化测试
- [x] 禁用设定与隔离数据严格不可见
